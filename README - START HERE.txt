TUMBLR SCRAPER - START HERE

1. Extract this folder.
2. Open the launcher for your computer:

   Windows: Start Tumblr Scraper - Windows.bat
   macOS:   Start Tumblr Scraper - macOS.command
   Linux:   Start Tumblr Scraper - Linux.desktop
   Android: open app/Tumblr Scraper - Android.py in Pydroid 3

3. The local archive opens in your browser.
4. Enter a public Tumblr blog and start a bounded crawl.

This preserves the target blog together with a bounded public Tumblr
neighborhood around it. Read README.md for details, CLI use, troubleshooting,
and power-user documentation.
