# Future implementation plans

Plans in this folder are approved plans for possible future implementation. Agents should keep them in consideration while working and may point out when a plan would fit the current work, for example: "hey, now would be a good time to implement planA while we are working on planF."

These plans are not tabled for execution merely by being stored here. Do not implement, partially implement, or treat them as active work unless the user explicitly asks for that plan or otherwise clearly authorizes its execution.

The documents in this folder preserve planning decisions and constraints. Their instructions describe future work; they do not override the current user request or authorize code changes.
